# Soft Launch — Watchlist

Cinematic watchlist with vibe-tagged shelves. Frontend-only React portfolio starter — smallest surface area in the set.

## Run

```bash
npm install
npm run dev
```

Opens on Vite (default `http://localhost:5174`).

## What ships

- Shelves UI with seed movies/shows (a couple Marvel titles included as content)
- Empty + loading patterns
- Up-next queue page with starter reorder buttons
- Persistence stubs for her feature work
